# MobileTune

אפליקציית Android בעברית עם ממשק מודרני לבחירת קובץ אודיו, השמעת תצוגה מקדימה ופתיחת החייגן הרגיל.

## חשוב לדעת
אפליקציית Android רגילה אינה יכולה להחליף באופן חופשי את אודיו המיקרופון בקובץ MP3 במהלך שיחה סלולרית. הפרויקט הזה מנגן אודיו מקומית ופותח את החייגן, ואינו מעביר את המוזיקה לצד השני.

## בניית APK
ב-GitHub פתחו Actions ואז Build Android APK ואז Run workflow. בסיום הבנייה, הורידו את MobileTune-debug-apk מתוך Artifacts.
