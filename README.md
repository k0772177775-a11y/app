# LifeHub

אפליקציית Android בעברית שמרכזת כלים שימושיים לניהול היום־יום, בממשק מודרני עם מצב כהה.

## מה יש באפליקציה
- לוח בקרה עם קיצורי דרך וסיכום משימות, הוצאות ומסמכים.
- רשימת משימות, אירועים ליומן ומטרות אישיות.
- רישום הוצאות וחישוב הסכום המצטבר.
- בחירת תמונות וקובצי PDF ושמירתם ברשימת מסמכים.
- תכנון מסלול על ידי פתיחת Google Maps עם מוצא ויעד.
- פתקים אישיים והגדרת מצב כהה.
- שמירת הנתונים במכשיר, ללא צורך בחשבון משתמש.
- קרדיט בתחתית האפליקציה: **נוצר ע"י מטען נייד**.

## הערות על הגרסה
זוהי גרסה ראשונית. הנתונים נשמרים מקומית במכשיר. תזכורות מערכת אוטומטיות, סנכרון ענן, חילוץ טקסט (OCR) ויצירת PDF מסריקה אינם כלולים עדיין.

## בניית APK
פתחו את לשונית Actions ואז את Build Android APK. לאחר שהריצה מסתיימת בהצלחה, הורידו את `LifeHub-debug-apk` מתוך Artifacts.
